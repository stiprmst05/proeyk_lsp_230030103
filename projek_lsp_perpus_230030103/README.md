## SIstem Penambahan Buku Perpustakaan

## Deskripsi
Sistem digunakan untuk mengelola data buku pada perpustakaan. 
Program ini memungkinkan admin untuk melakukan pengelolaan data buku seperti menambah, melihat, dan menghapus data buku.

## Fitur Program
Menampilkan Data Buku
Menambahkan Data Buku
Menghapus Data Buku

##Teknologi yang Digunakan
PHP
MYSQL

## Struktiur folder
projek_lsp_perpus_230030103: Berisi file konfig, database perpustakaan, sistem login, dan halaman login
buku: Berisi file halaman daftar buku, sistem penghapus dan penambah, dan halaman tambah buku

## Cara Menjalakan Program
1. instalasi XAMPP
2. copy folder projek_lsp_perpus_230030103 ke htdocs
3. import database perpustakaan ke phpMyAdmin
4. jalankan apache dan mysql
5. jalankan dibrowser dengan alamat http://localhost/projek_lsp_perpus
6. login kepada sistem dengan user Admin dan password 123
